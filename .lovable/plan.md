### 2. Notion template

Notion templates are best shipped as a **Markdown bundle** that imports cleanly into Notion (File → Import → Markdown & CSV).

Create `public/sovereign-sprint-notion.zip` containing:

```text
Sovereign Sprint/
  README.md                  -- import instructions
  00 — Start Here.md         -- mission, how to use, the 4 pillars
  01 — 90-Day Vision.md      -- vision, non-negotiables, success metrics
  02 — Daily Log (Template).md  -- one prompt + 3 rituals + one-line truth
  03 — Weekly Reflection (Template).md  -- 5 questions
  04 — 30·60·90 Milestones.md
  Days/
    Day 01.md ... Day 90.md  -- pre-stamped from the daily template
```

Each file uses Notion-friendly Markdown (H1 title, callouts as `> `, checkboxes as `- [ ]`, simple tables). Generated by a Python script in `/tmp` then zipped.

### 3. Obsidian template
